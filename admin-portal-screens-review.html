Admin Portal — Screen Review

Please review the admin screens below for look, feel, and scope. This portal is for United Securities staff to manage fund documents, master data, reports, and operational views. Account / KYC approval remains with Gulf Custody (not in this portal).

Prepared for client confirmation · Desktop web portal
How to review: Check each screen for layout, colours (usoman.com gold + navy), wording, and whether the admin journey is clear for your operations team.
Scope note (from BRD): Admin Portal manages accounts views, documents, master data, and reports. It does not approve or reject investor KYC / accounts — that stays with Gulf Custody.

11. GCC API List Excel V6.0 — full sheet mapping

Checked file: Docs/GCC API List-2024 V6.0 (1) (2).xls · 13 sheets. How each API maps to Admin Portal vs Mobile vs Gulf Custody.

Excel sheet What it covers Admin Portal Investor mobile
Client On Boarding CIF, name, title (MR/MRS/MS), gender, DOB, nationality, residence status, address, mobile, email, legal ID + dates, customer type (Individual / Company / Others), bank account(s), SWIFT. Response: Master Account Number. View investor / status only. Map reference lists (title, gender, residence, customer type). KYC form collects these fields → sent to GCC. Approve stays with GCC.
Unit Subs_Redem Shareholder + bank details, Fund id (e.g. E16GR / E71GR), SUB or RED, Unit or Amount, Quantity/Amount, Payment Method, Transaction Date, Image Id. Response: Transaction ID, Master Account Number + confirmation email/PDF from GCC. Orders work queue — monitor status, cut-off flag, export. Subscribe / Redeem / SIP flows call this API via BFF.
Sub_Red Enquiry Enquiry by Client ID (+ optional Fund Code, date, ref). Returns SUB/RED flag, amount, units allocated, NAV (sample fund E71GR, NAV 1.4657). Order detail / status refresh from custody. History & order status screens.
SOA - Unit Holder Statement of accounts by Client ID + date range. Fund Code/Name, Transaction Type (Subscription/Redemption), units, price, amount, load/fees, opening/closing balance. Investor statement report / export. Transaction history / statement download.
Unit Holder Statement As-on holdings: Fund Code + Class, Client ID/Name, Account Type (Individual/Corporate/Joint), Unit Balance, Current Net Value. Investor holdings view / AUM reports. Portfolio & home total value (units × NAV).
NAV Request by Fund Code (optional) + From/To date (max 15 days). Returns Class Code, Fund Currency, NAV Date, Net Assets, fee types/amounts, Units Outstanding, NAV Per Unit, Previous NAV, Percentage Change. NAV monitor screen — sync & view (not manual invent of prices). Fund details, portfolio valuation, performance %.
NAV-Not Used Older NAV request (Fund Code + NAV Date) — marked Not Used; email PDF response model. Ignore for build — use active NAV sheet. —
ISO Codes Currency codes (OMR, USD, …) + Stock Exchange codes (MSM, DFM, KSE, …). Reference master — view / sync lookup lists. Used in KYC & bank currency dropdowns.
Holidng List Fund holdings as-on date. Holding Type 1 = Deposits, 2 = Other. Deposits: counterparty, amount, tenor, rate… Securities: ISIN/name, market value, G/L, % of capital. Optional fund holdings / research ops view (not retail portfolio). Not shown as investor “my units” (that is Unit Holder Statement).
Bank Account Transactions Fund bank movements (max 15 days): Redemption / Bank Transfer / Deal Settlement / JV / Dividend… Debit/Credit, amount, narration. Ops cash / bank movement report (fund-level). Not investor-facing.
Fixed Deposit Inward Deposit Deal API for fund treasury (Fund Code e.g. E74, deposit type C/W/M/S, rates, placement/maturity accounts). Fund setup must maintain GCC fund unique code + bank accounts. Out of retail investor scope (unless later treasury module). —
Deals other than FD MM / security deals (BUY/SELL, ISIN, broker, depository, exchange, commissions). Out of retail investor scope (fund trading desk). —
Order Confirmation Confirm deposit/deal orders (status Placed / Cancelled / To be Placed). Linked to Fixed Deposit / deals ops — not retail subscribe. —
Fund codes in Excel samples: E74, E71GR, E16GR, 102067-1 … United Securities UAT funds in use for the investor app: E71 (United GCC Fund), E59 (United US Markets Fund). Excel note: during fund setup, maintain GCC Fund Unique Code + fund bank accounts in GCC.

What Admin Portal owns (not in Excel)

  • Upload / publish Factsheet, Prospectus, T&Cs, Risk disclosures (shown in mobile)
  • Fund marketing master: EN/AR names, risk label, min subscription, cut-off time, featured flag
  • Notification templates (SMS / Email / Push) per BRD matrix
  • Reports, audit log, staff users & roles

What stays with Gulf Custody

  • KYC / account approve or reject (Admin is view-only)
  • Official units, NAV, confirmations, statements (golden source)
Client takeaway Admin Portal = documents + channel master data + ops views of GCC data. Retail subscribe/redeem/KYC data shapes come from the Excel sheets above; custody remains system of record.
